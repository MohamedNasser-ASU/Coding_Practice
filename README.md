# Coding Practice

A collection of programming exercises and small projects I build while learning and practicing different languages and programming concepts.

## Languages

* **C** — fundamentals, system programming, processes, terminal programs, and general practice.
* **Java** — Object-Oriented Programming and small system-design exercises.

## Repository Structure

```text
Coding_Practice/
├── C/
|   ├── C programs
│
└── Java/
    ├── OOP
```

## C Practice

The C directory contains small programs used to practice concepts such as:

* Functions and control flow
* Pointers and strings
* Standard library usage
* Processes with `fork()` and `exec()`
* Command-line programs
* Terminal and system-level programming

## Java Practice

The Java directory contains small projects focused on Object-Oriented Programming concepts including:

* Classes and objects
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Interfaces
* Enums
* Exception handling
* Method overriding
* Basic system design

## Purpose

This repository is mainly a personal practice space. It will continue to grow as I learn new concepts, languages, and lower-level programming topics.
